# Operating Systems

Coursework for Operating Systems at Chung-Ang University: process API exercises in C, scheduling examples, and chapter notes.

## Contents

| Path | What's inside |
|---|---|
| `code_file/p1.c` to `p4.c` | Process API exercises with `fork`, `exec`, and `wait` |
| `code_file/Example_lottery_ticket_code.c` | Lottery (proportional-share) scheduling example |
| `md_file/` | Chapter notes: processes, CPU scheduling (MLFQ, proportional share, multiprocessor), memory virtualization (segmentation, paging, TLB), and concurrency (locks) |
| `PR2.txt` | xv6 project setup on Ubuntu (build tools, QEMU, xv6 source) |
| `PR2_2.txt` | xv6 kernel source written for the project |

C, Linux
